# Яндекс Алиса + Gemini на Vercel или Deno Deploy

> Основано на шаблоне [ruslanpodzorovraw-collab/alice-gemini-serper-template](https://github.com/ruslanpodzorovraw-collab/alice-gemini-serper-template) (MIT).

> ⚠️ **Временно:** из-за проблем на стороне Яндекса при настройке навыка в Яндекс Диалогах **выключите** «Использовать хранилище данных в навыке». Память разговора навык хранит сам в базе Upstash (см. ниже), так что хранилище Яндекса не нужно.

> 🇷🇺 Серверы Алисы находятся в России, где адреса `*.vercel.app` блокируются. Если навык отвечает «Извините, навык не отвечает», разместите его на Deno Deploy — см. раздел «Размещение на Deno Deploy».

Готовый шаблон вебхука для навыка Яндекс Алисы. Вам не нужно редактировать код: разместите этот репозиторий в Vercel, добавьте два API-ключа и укажите адрес вебхука в Яндекс Диалогах.

## Как развернуть

1. Код уже лежит в этом репозитории — форк не нужен.
2. Откройте https://vercel.com/dashboard и нажмите **Add New… → Project**.
3. В списке **Import Git Repository** выберите этот репозиторий и нажмите **Import**.
4. Нажмите **Deploy** и дождитесь завершения первого развёртывания.
5. В проекте Vercel откройте **Settings → Environment Variables**.
6. Создайте переменные окружения ниже, выбрав **Production** для каждой:
   - **Key:** GEMINI_API_KEY — **Value:** ключ из Google AI Studio: https://aistudio.google.com/app/apikey
   - **Key:** TAVILY_API_KEY — **Value:** ключ из Tavily для поиска в интернете: https://app.tavily.com (необязательно, см. ниже)
7. После сохранения ключей откройте **Deployments** и выберите **Redeploy** для последнего Production-развёртывания. Дождитесь статуса **Ready**.
8. В Vercel откройте **Settings → Domains**, скопируйте свой домен и добавьте в конец /api. Например: https://YOUR-PROJECT.vercel.app/api.
9. Откройте свой навык в Яндекс Диалогах. В настройках Backend вставьте этот полный адрес в **Webhook URL** и сохраните изменения.
10. Опция **Использовать хранилище данных в навыке** сохраняет контекст между репликами. **Сейчас её нужно выключить** (см. предупреждение в начале) и включить, когда Яндекс исправит проблему.

Названия разделов могут немного отличаться при обновлении интерфейса. Используйте только свой домен Vercel — не копируйте адрес автора шаблона.

## Если вы скачали ZIP

1. Распакуйте ZIP двойным кликом.
2. В своём GitHub нажмите **+ → New repository** и создайте репозиторий.
3. Откройте его и выберите **Add file → Upload files**.
4. Перетащите содержимое распакованной папки в браузер. Не потеряйте папку api и файл api/index.js внутри неё.
5. Нажмите **Commit changes**.
6. Вернитесь к шагу 2 в разделе выше и импортируйте репозиторий в Vercel.

## Какие ключи нужны

- **GEMINI_API_KEY** обязателен для ответов нейросети.
- **TAVILY_API_KEY** включает поиск в интернете через Tavily: 1000 бесплатных запросов в месяц, лимит обновляется ежемесячно, карта не нужна. Ключ начинается с `tvly-`.
- **SERPER_API_KEY** — другой вариант поиска, через Serper (разовый бесплатный запас запросов). Если заданы оба ключа, используется Tavily.
- Если не задан ни один ключ поиска, обычные ответы Gemini всё равно работают, но про погоду, новости и курсы навык ответит без свежих данных.

Вопросы о погоде («какая погода в Казани», «нужен ли завтра зонт», «сколько градусов на улице») обрабатываются без поиска: навык берёт данные напрямую из бесплатного [Open-Meteo](https://open-meteo.com) — без ключа и регистрации, быстрее и точнее поиска. Город берётся из вопроса; если он не назван, используется Новосибирск. Другой город по умолчанию можно задать переменной **WEATHER_CITY** (например, `Москва`). Если город не найден, навык ищет погоду обычным поиском.

Поиск включается не на каждый вопрос, а только когда в нём есть слова вроде «сегодня», «сейчас», «погода», «новости», «курс», «найди» — так бесплатные запросы расходуются медленнее. Если поиск не ответил вовремя или закончился лимит, навык просто отвечает без него.
- **GEMINI_MODEL** необязателен. По умолчанию используется gemini-3.5-flash-lite. Если эта модель недоступна для вашего API-ключа, укажите точное имя другой доступной модели Gemini.
- **GEMINI_FALLBACK_MODEL** необязателен. По умолчанию gemini-3.1-flash-lite. Навык задаёт вопрос сразу двум моделям и берёт тот ответ, который пришёл первым: так меньше таймаутов, когда Gemini перегружена. Чтобы отключить запасную модель, задайте пустое значение.

Ключи вводятся только в **Vercel → Settings → Environment Variables**. Не размещайте их в исходном коде, GitHub, README, Яндекс Диалогах или сообщениях. Если ключ попал в открытый доступ, отзовите его и создайте новый.

## Как проверить навык — без команд и программирования

**Самый простой способ — проверить его голосом на колонке или через приложение с Алисой.**

1. Убедитесь, что в Яндекс Диалогах у навыка указан ваш адрес Vercel в поле **Webhook URL**, который заканчивается на `/api`.
2. В настройках навыка выберите тип доступа **Приватный** и сделайте навык доступным для тестирования. Для голосового запуска войдите на колонке или в приложении с Алисой в тот же аккаунт Яндекса, которым вы пользуетесь в консоли разработчика.
3. Скажите: **«Алиса, запусти навык [название или активационное имя вашего навыка]»**. Например, вместо скобок произнесите настоящее название, которое вы указали в настройках навыка.
4. Когда Алиса запустит навык, задайте обычный вопрос и проверьте, что она отвечает.

Если Алиса не находит навык или вы ещё не сделали его доступным для голосового запуска, откройте Яндекс Диалоги → свой навык → **Тестирование**. Этот встроенный тестер подходит для первой проверки до публикации и показывает ответ навыка.

Если всё работает в тестере, но не работает через колонку, проверьте, что навык доступен для голосового запуска, на колонке выбран тот же аккаунт Яндекса и произносится правильное активационное имя. Инструкция Яндекса: https://yandex.ru/dev/dialogs/alice/doc/ru/test

## Проверка настроек в браузере

`https://ВАШ-АДРЕС/api` отвечает просто `{"ok":true}` — значит, сервер работает. Подробности посторонним не показываются.

Чтобы видеть настройки и проверять подключения, откройте `https://ВАШ-АДРЕС/api?check=СЕКРЕТНОЕ-СЛОВО`. Секретное слово записано в `api/index.js` (константа `DEFAULT_HEALTH_TOKEN`); его можно заменить переменной окружения **HEALTH_TOKEN**. Отчёт покажет, задан ли ключ Gemini и какие модели используются, какой поиск и город погоды настроены, а также по-настоящему проверит подключения: принимает ли Google ключ, работает ли ключ поиска (для Tavily — сколько запросов потрачено из лимита), отвечает ли база Upstash. Проверка не тратит лимиты Gemini и поиска.

В разделе `checks` у каждой части есть `ok` и `status`. `"ok": true` в начале ответа означает, что навык может отвечать (Gemini работает); поиск и база необязательны, их состояние смотрите отдельно.

## Размещение на Deno Deploy

Тот же код запускается на бесплатном [Deno Deploy](https://deno.com/deploy): файл `main.js` принимает запросы и передаёт их в `api/index.js`. Адреса Vercel из России блокируются, а Deno Deploy (на момент проверки) открывается.

1. Откройте https://console.deno.com и войдите через GitHub.
2. Создайте приложение (**New App**) и выберите этот репозиторий.
3. В настройках сборки: шаблон фреймворка — без шаблона (**No preset**), команды установки и сборки — пустые, точка входа (**Entrypoint**) — `main.js`.
4. В настройках приложения добавьте переменные окружения — те же, что в Vercel:
   - `GEMINI_API_KEY`, `TAVILY_API_KEY` (если нужен поиск), `WEATHER_CITY` (если нужен другой город);
   - `KV_REST_API_URL` и `KV_REST_API_TOKEN` — подключение к базе Upstash. Значения можно посмотреть в Vercel → **Settings → Environment Variables** или в консоли Upstash → ваша база → раздел **REST API** (там они называются `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` — подойдут и с такими именами).
5. Запустите развёртывание. Deno Deploy выдаст адрес приложения; дальше он будет сам обновляться при каждом изменении в ветке `main`.
6. **Проверьте, что адрес открывается из России:** откройте `https://АДРЕС/api` с телефона через мобильный интернет без VPN.
7. Откройте `https://АДРЕС/api?check=СЕКРЕТНОЕ-СЛОВО` (см. «Проверка настроек в браузере») и убедитесь, что Gemini, поиск и база в порядке.
8. В Яндекс Диалогах укажите **Webhook URL** = `https://АДРЕС/api`.

Если не открывается и Deno Deploy, можно подключить свой домен (у Vercel — **Settings → Domains**): блокировки обычно стоят на конкретные имена, а нового домена в них нет.

## Если навык не отвечает

1. Проверьте, что имена переменных написаны без опечаток и выбрано окружение **Production**.
2. После изменения ключей выполните **Redeploy** и дождитесь статуса **Ready**.
3. Проверьте правильность **Webhook URL**: домен должен быть вашим, путь должен заканчиваться на /api.
4. Откройте последнее развёртывание в Vercel и проверьте логи. Перед отправкой логов в ChatGPT удалите из них секретные данные.

## Ограничение времени ответа

Яндекс Диалоги ожидают ответ от навыка около 4,5 секунды, а Gemini под нагрузкой иногда думает дольше. Без дополнительной настройки навык в таком случае говорит «Не успела подготовить ответ».

### Режим «отвечу следующей репликой» (рекомендуется)

Если подключить бесплатную базу Upstash Redis, навык не теряет медленные ответы: когда ответ не готов за ~3 секунды, Алиса говорит «Секунду, ещё думаю. Скажите „ну что“», а сервер продолжает ждать Gemini. На «ну что» (или «что там», «готово», «дальше») Алиса произносит готовый ответ. Быстрые ответы по-прежнему приходят сразу.

Как подключить:

1. В проекте Vercel откройте **Storage** → **Create Database** (или **Browse Marketplace**) → **Upstash** → **Redis**.
2. Выберите бесплатный план и регион поближе к региону функций Vercel (по умолчанию — Washington, D.C., `iad1`, то есть US East).
3. На шаге подключения выберите этот проект и окружение **Production**. Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
4. Сделайте **Redeploy**.
5. Откройте проверку настроек (`/api?check=СЕКРЕТНОЕ-СЛОВО`, см. выше) — в ответе должно быть `"deferredAnswers": true`.

Та же база хранит и **память разговора**: последние реплики сессии (до 16, то есть 8 вопросов и 8 ответов) хранятся 30 минут, поэтому навык понимает уточнения вроде «а сколько ему было лет?» или «а подробнее?». Это работает даже с выключенным «хранилищем данных» Яндекса. Каждый запуск навыка начинает разговор с чистого листа.

Если база создана напрямую на upstash.com, добавьте в Vercel переменные `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` из её карточки (раздел REST API).
